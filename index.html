Installation

🚧 In development

The installer is still in development. Here is what the setup will look like.

1. Prepare the server

Linux, PHP, MariaDB, Redis and a web server (Nginx).

2. Install the panel

Get HeadyCore from GitHub, configure the environment and migrate the database.

3. Add a node

Install Wings, link it to the panel and create your first server.
